Pluie Noire

Données personnelles et confidentialité

Pluie Noire est un jeu gratuit qui se joue dans le navigateur. Cette page explique ce qui est enregistré, où, et comment l'effacer.

Sans compte

Ta partie est enregistrée uniquement dans ton navigateur, sur ton appareil. Rien n'est envoyé ailleurs. Le jeu n'utilise ni cookie publicitaire, ni mesure d'audience.

Le code de transfert et le QR code contiennent ta sauvegarde (progression, choix, statistiques de jeu), sans aucune donnée personnelle.

Avec un compte

  • Ce qui est enregistré : ton adresse e-mail (et ton nom si tu te connectes avec Google), un identifiant technique, et ta sauvegarde de partie.
  • Pourquoi : uniquement pour retrouver ta partie sur tous tes appareils. Ces données ne sont ni vendues, ni utilisées pour de la publicité.
  • Où : chez Google Firebase (Authentication et Cloud Firestore). Les sauvegardes sont stockées dans l'Union européenne ; le service de connexion de Google peut traiter des données hors de l'Union européenne, dans le cadre des garanties contractuelles de Google.
  • Combien de temps : jusqu'à ce que tu supprimes ton compte.

Tes droits

Tu peux à tout moment supprimer ton compte et ta sauvegarde en ligne depuis l'écran « Mon compte » du jeu (bouton « Supprimer mon compte »). Le code de transfert te donne une copie complète de ta sauvegarde.

Pour toute autre demande (accès, rectification, question), écris à l'auteur du jeu via la page du projet. Tu peux aussi adresser une réclamation à la CNIL.
